# Features that do not work on ForeverCore yet (slice 1, package R6A)

The to-do list of the later slices. Each row is one entry of the closed table in `ai/playerbot/UnportedFeatures.h`; on ForeverCore its helpers
(`forever/src/compat/TbCompat_Unported.h`) call `tbcompat::Unported(Feature::X)`, which counts the call, logs the first one per name
(`TortoiseBots: not ported yet: <name>`) and returns the failure value in the table below: "the action did not happen", never an invented value.
On Turtle (`ai/cmangos-compat-unported.h`) every helper is the original call. The boot line and `.tb unported` print the counts (host lines in
`SLICE1-R6A-NOTES.md`, "NEEDS FROM host"). A later slice that ports a feature deletes its row, its enum entry and its helpers.

58 features. "Call sites" are the places in the legacy tree that call a helper of the feature (or a `UnportedBlock*Compat` with it), counted by the build tree at the commit of this file; the `Incoming:` rows count packet table rows (the tables hold 54 rows; packet cases dealt with directly are counted by `RegisterDirectPacketCasesCompat`).
